<h3 align="left">Selected projects & research</h3>

- **[Usta — Native macOS Multi-Agent IDE](https://github.com/danialza/Usta)**  
  A native macOS workspace where specialist AI agents collaborate on software projects. Built with a Swift frontend and a Rust/Tokio backend, using gRPC, terminal sessions, and a shared event bus.

- **[TalkingHeadAI — Conversational AI](https://github.com/danialza/TalkingHeadAI)**  
  A conversational AI application combining retrieval, LLM-powered responses, backend APIs, and policy-based response checks, designed around practical interactions and responsive user experiences.

- **[AEGIS — Robot Safety Research](https://github.com/danialza/aegis-safe-action-layer)**  
  Public research data, figures, and reproducibility materials for an age-aware robot safety approach using RGB-D sensing and vision-language monitoring on the Niryo NED3 Pro.

- **[Adaptive Robot Control — Published Research](https://github.com/danialza/hardware-aware-nussbaum-pid)**  
  Research code and experimental materials for deploying and evaluating adaptive control on real robot hardware. [Published in *Sensors* (2026)](https://doi.org/10.3390/s26134212).

<h3 align="left">How I approach engineering</h3>

- **Build for people:** start with the problem and design around real usage.
- **Keep systems understandable:** favor clear interfaces, useful abstractions, and maintainable code.
- **Measure before optimising:** use profiling, benchmarks, and evidence to guide technical decisions.
- **Own the whole solution:** think about integration, reliability, deployment, and what happens after release.
- **Keep learning:** bring ideas from AI, robotics, and systems engineering into practical products.
